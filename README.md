# HLL Vietnam Mortar Calculator

A lightweight installable web app for Hell Let Loose: Vietnam mortar calculations.


## Install on iPhone

1. Open the GitHub Pages URL in **Safari**.
2. Tap the **Share** button.
3. Tap **Add to Home Screen**.
4. Tap **Add**.

The app supports offline use after it has been opened once successfully.

## Modes

- **Basic**: fire-control calculator only.
- **Full**: calculator + 3 saved distances + last 5 targets.

Mode, saved distances, and target history are stored locally on the device.
